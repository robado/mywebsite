# Robert Ridal's Portfolio Website

A modern, full-stack personal portfolio website featuring:

- **Frontend**: Clean, responsive design with dark mode support
- **Backend**: Node.js/Express with JWT-based authentication
- **Database**: PostgreSQL for user management
- **Authentication**: Secure login with password hashing (bcrypt)
- **Features**: Sign in/logout flow with server-side session validation

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Express.js
- **Database**: PostgreSQL
- **Authentication**: JWT (jsonwebtoken), bcrypt
- **Deployment**: GitHub Pages (frontend)

## Project Structure

```
├── public/          # Frontend assets and pages
│   ├── assets/      # CSS, JS, images
│   └── pages/       # HTML pages (home, about, contact, etc.)
├── db/              # Database configuration
├── middleware/      # Express middleware
├── server.js        # Express server & API routes
└── db.js            # Database connection
```
